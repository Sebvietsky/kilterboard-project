# Kilterboard API

Backend NestJS de l'application Kilterboard.

## Status du projet

### Front
A venir

### Back
API terminé pour un MVP

## Stack
- NestJS + TypeScript strict
- PostgreSQL 16 + Prisma
- JWT + bcrypt

## Lancer en local

```bash
npm install
npm run start:dev
```

## Scripts

```bash
npm run lint        # ESLint
npm run type-check  # TypeScript check
npm run test        # Jest
npm run build       # Compilation
```
